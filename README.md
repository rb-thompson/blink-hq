# Blink HQ ⚡

Mission control center for an AI agent-powered operation.

## Structure

- `apps/mission-control/` — Next.js dashboard for agent orchestration
- `apps/visualizer/` — 8-bit retro office visualizer
- `agents/` — Agent configurations, prompts, and role definitions
- `packages/shared/` — Shared libraries and types
- `infra/` — Docker configs, scripts, backups
- `docs/` — Architecture docs and notes

## Stack

- **Frontend:** Next.js, TypeScript
- **Providers:** Anthropic, xAI, NVIDIA
- **Orchestration:** OpenClaw
- **Deployment:** Railway / Vercel
